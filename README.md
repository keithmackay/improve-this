# new-model-review-skill

## Description

A Claude Code skill that evaluates an existing project for potential improvements across multiple dimensions: UI/UX, scalability, load performance, calculation speed and accuracy, search speed and accuracy, test coverage and quality, token usage efficiency, and general code efficiency. Designed to be run with different AI models (or newly-released models) to surface different improvement perspectives on prior code. The skill is strictly evaluate-and-report — it never makes changes. At the end of a review, the user is offered the option to generate a spec and implementation plan for any improvements found.
